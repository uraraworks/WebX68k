# コア最適化フラグの比較

2026-10-28。emscripten 6.0.7、Node.js v26.10.0。ゴールデンと同じ ROM・ディスク・オプション、UTC、Date.now を固定値からフレームごとに 18ms 進め、900 フレーム目から dir を入力する。1巡 1200 フレーム、最初の巡を捨て、残り5巡を同一プロセスで交互に測定。各セルは各巡のフレーム中央値または p90 の中央値（ms）。_retro_run にはコールバック内の映像・音声変換も含む。計測器呼び出しのオーバーヘッドを含む。

測定の床: A1/A2 の対応する巡の中央値の相対差の最大は 0.93%（retro_run、runFrame とも）。速度差は各巡の A に対する中央値の相対差の中央値。絶対値が床以下なら差なし。

| 変種 | ゴールデン | retro_run 中央値 / p90 ms | runFrame 中央値 / p90 ms | A比（床判定） | wasm 生 / gzip bytes |
|---|---|---:|---:|---:|---:|
| A `-O2` | 一致 | 1.3649 / 1.6009 | 1.3650 / 1.6010 | +0.00%（基準） | 680,118 / 155,460 |
| B `-O3` | 一致 | 1.3821 / 1.6180 | 1.3821 / 1.6182 | +2.09%（遅い） | 679,122 / 161,139 |
| D `-O3 -msimd128` | 一致 | 1.3516 / 1.5564 | 1.3517 / 1.5565 | -1.14%（速い） | 692,484 / 163,796 |
| C `-O3 -flto` | 未検証（ビルド失敗） | — | — | — | — |
| E `-O3 -flto -msimd128` | 未検証（ビルド失敗） | — | — | — | — |

C・E のエラー: `clang: error: no such file or directory: .../emscripten/system/lib/gl/gl.c`。LTO 用システムライブラリ生成時の相対パス解決に失敗。

推奨: D。映像・音声の3試験が一致し、対応する巡の中央値の改善が測定の床をわずかに超えた。ただし差は小さく巡ごとのばらつきもあるため、採用前に対象環境で再測定したい。SIMD は [Safari 16.4 以降](https://webkit.org/blog/13966/webkit-features-in-safari-16-4/) で対応し、古いブラウザ向けには非 SIMD 版が必要。

既定ビルドの変更前後の SHA-256 は JS `80ff2f0759f7f74009b3561178efa80d7b7bb1db6e4fdf68ab3340fd7cf5a80d`、wasm `1a50ee7fd034ce2960f6d08a4344750b7100efdc06100792f9cd03d4ac87e7cc` でそれぞれ一致。既定フラグは変更していない。

**採否（2026-10-28）: 現状維持（-O2）。** D の改善 1.14% は床 0.93% とほぼ同じ大きさで、SIMD 非対応ブラウザ向けに非 SIMD 版を併せて配る手間に見合わない。LTO は emsdk 側でビルドできないため、emsdk 更新時に C・E を測り直す。
